# Released as free open source under AGPLv3

The editor is published for free on GitHub so others can use it and port it (for example to Windows). JUCE is free for open-source projects only under AGPLv3, so the whole project uses AGPLv3; a permissive licence such as MIT would require a paid JUCE licence.

## Consequences

- Anyone may modify and redistribute the editor, but derived versions must stay open source under AGPLv3.
- Third-party material that is not ours to relicense (Clavia manuals, factory sound banks, the commercial AURA Plugins editor) stays out of the repository.
