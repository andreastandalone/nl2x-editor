# NL2X Editor 0.1.0-beta.1

The first public beta of NL2X Editor, a free, open-source editor for the Nord Lead 2X and Nord Rack 2X: a VST3 and Audio Unit plugin and a standalone app for macOS 11 or later, Universal for Intel and Apple Silicon.

## Download

Download the formats you need below, unzip and copy:

- `NL2X-Editor-VST3.zip`: copy `NL2X Editor.vst3` to `/Library/Audio/Plug-Ins/VST3/`
- `NL2X-Editor-AU.zip`: copy `NL2X Editor.component` to `/Library/Audio/Plug-Ins/Components/`
- `NL2X-Editor-App.zip`: copy `NL2X Editor.app` to `/Applications/`

The first time, macOS blocks it: open System Settings > Privacy & Security and click **Open Anyway**. MIDI and synth settings are in the [README](https://github.com/andreastandalone/nl2x-editor#midi-settings).

## Features

- Every sound parameter of Slots A–D, Morph Amounts included.
- Two-way: the synth's panel and the editor follow each other.
- Every parameter is a DAW parameter, for automation and controller mapping.
- Your DAW project recalls the synth's sounds.
- Bank, Program and Performance selectors.
- Connection check that says what to fix.
- Library of your `.syx` files, with names, tags, favourites and instant Audition.
- Librarian for the synth's Banks 0–3, with automatic backups and read-back.
- Undo and redo.
- Resizable window, 75 % to 200 %.
